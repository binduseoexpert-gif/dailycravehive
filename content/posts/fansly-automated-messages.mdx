## Open Automated Messages And Create One

Official help points you to Automated Messages in the Creator Dashboard, then tells you to select **Create New Automated Message**. If your current dashboard uses a different menu name or icon, confirm what is on screen rather than assuming the December 2025 label is unchanged.

The setup article uses the same order each time: choose a trigger, set a delay, add a cooldown period, apply any custom settings, edit the message, then click **Create**. You can also click **Edit** later when you create or update an automation. Official help does not publish a limit on how many automations you can keep, and it does not say whether two automations can fire on the same action. If you add more than one automation for a similar event, confirm the send by searching the fan's name or using the envelope icon.

## Choose A Trigger

Official help lists the triggers you can assign to an automation. "Welcome message" is a common way to describe the first note a new follower or subscriber receives. It is not the official name of a trigger. The official labels are the ones below.

**New follower** is "sent whenever someone follows." Official help does not add extra conditions to that trigger.

**New subscriber**, **Gift link subscriber**, and **Subscription renewal** are grouped together in official help. For any of these, "you can have one message for all subscription tiers, or customize the message for a specific tier." Official help does not publish a suggested welcome script or a rule about running both an all-tier message and a tier-specific message at the same time. If you use both, confirm in a sent thread what that fan actually received.

**New Tip** is the trigger official help ties to a tip menu. The setup article says that for tips, "you can set a keyword or amount. Using these together, you can create a menu of content users can tip for!" The newer Messaging article names the field labels: "Want to offer custom content requests through tips? You can even enable Keywords and set a Minimum Tip Amount on your New Tip trigger to send your fans a menu or prompt when they send a qualifying tip." Official help does not publish required keywords or a required minimum amount, so this guide does not invent a menu or rates. A tip-triggered send can include locked text, but pricing locked media and reading sale stats are outside this article.

**Disabled** is not a send trigger. Official help says to use it "to temporarily turn off an automation without deleting it. You can easily switch the trigger again when you're ready."

## Set A Delay, A Cooldown And Any Custom Settings

After the trigger, official help tells you to "set a delay (in seconds) before the message is sent." Seconds is the official unit for the delay. Official help does not publish a default, a minimum, or a maximum.

Next, official help tells you to "add a cooldown period to avoid sending the same message repeatedly to the same person." The setup article does not, in the text we checked, name a unit or a required length for the cooldown the way it names seconds for the delay. Set the period in the field the current dashboard shows, and read the label next to that field.

Official help also lets you "apply custom settings like targeting specific subscription tiers or tip amounts." That matches the per-tier option on subscription triggers and the amount option on New Tip. If the current dashboard shows more filters than the help article names, use the labels you can see and keep any extra filter unclaimed unless official help describes it.

## Edit The Message, Then Click Create

To write the message, official help says to click **Edit** when you create or update an automation. The message "can include any or all of these options":

- The message text
- Attached media
- Locked text
- Voice notes

Official help does not describe formatting tools, GIFs, or a tip-request button as part of the automated-message editor, so this guide does not treat those as automated-message features. Locked text is named as an option you can include. To set a Pay price on locked media and read Sale Stats, see our [Fansly PPV](/fansly-ppv) guide.

When the trigger, timing, targeting, and message are set, official help says to click **Create**. To stop sends without deleting the automation, switch the trigger to **Disabled**.

## Find A Send That Does Not Open A New Thread

Automated messages are easy to miss in a busy inbox for one official reason: "Automated messages won't open a new DM thread in your inbox, helping you avoid clutter." Official help gives two ways to check that a message was sent:

- "Search their display name directly in your inbox" or
- "Go to the fan's profile and click the envelope icon"

If you expected a new conversation at the top of Messages, official help says that will not happen. Search or use the envelope icon instead. Official help does not publish a delivery log or a retry rule.

## What Fans See, And How That Affects Your Wording

The official Messaging FAQ asks, "Can fans tell if it's a mass or automated message?" The official answer is: "Nope! Fans see all messages the same way, whether it's sent manually, scheduled, or triggered automatically. There's no tag or label on their end."

That puts the wording burden on you. Because the fan cannot see a label, a line that says you are typing at that moment can be untrue if the send was delayed or triggered while you were away. Official help does not require any particular script. Write a message that stays accurate whenever it arrives, such as a thank you, a short pointer to where to start, or a menu or prompt after a qualifying tip.

A fan may also reply as if you sent the message by hand. Official automated messages are not a substitute for a person who can answer a custom question. Hiring inbox help is a different decision, covered in our OnlyFans chatters guide linked above.

## This Is Not A Mass Message, And Not Account Access

Mass messages are a different official Fansly tool. Official [Mass Messages help](https://help.fansly.com/en/articles/10544423-mass-messages), last updated November 10, 2026, describes them as a way "to communicate with a large number of followers or subscribers simultaneously, eliminating the need to message each person individually." You open them from Fansly Messages, choose **New Mass Message**, set an audience, optionally schedule the send, add text and media, and press **Send**. That is a one-to-many send you start, not a trigger that fires when a fan follows, subscribes, renews, or tips. This page does not walk through mass-message audience lists, scheduling, or media permissions.

Automated messages are also not official manager access. Our Fansly management sessions guide, linked above, covers how Fansly lets you grant a manager access without sharing your password. A trigger you write here still sends as your message, with no fan-facing tag.
